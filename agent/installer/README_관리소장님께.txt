   OO오피스텔 주차 관리 에이전트 — 설치 안내문
   작성: 관리사무소
════════════════════════════════════════════════════════════

이 프로그램은 오피스텔 방문차량 앱과 주차관제 시스템(Cartan)을
자동으로 연결하는 백그라운드 프로그램입니다.

──────────────────────────────────────────────────────────────
[ 설치 전 준비물 ]
──────────────────────────────────────────────────────────────

  1. USB에 담겨있는 설치 폴더 (officetel_agent_installer)
     - officetel_agent.exe   (에이전트 본체)
     - cartan_probe.exe      (DB 탐침 도구)
     - install.bat           (설치 실행 파일)
     - config.json.example   (설정 예시)
     - nssm.exe              (서비스 등록 도구)
     - README_관리소장님께.txt (이 안내문)

  2. 관리 담당자로부터 받은 값 2개:
     ☐ AGENT_TOKEN  (긴 영문 + 숫자 조합)
     ☐ GITHUB_TOKEN (자동 업데이트용)

──────────────────────────────────────────────────────────────
[ 설치 순서 — 한 번에 끝내기 ]
──────────────────────────────────────────────────────────────

  ━━━━ 1단계 : USB 폴더를 PC에 복사 ━━━━

    1) USB 안의 [officetel_agent_installer] 폴더를
       PC 바탕화면에 통째로 복사합니다.

  ━━━━ 2단계 : cartan_probe.exe 실행 ━━━━

    1) 복사한 폴더에서 [cartan_probe.exe] 더블클릭.
    2) 1~2분 자동 진행 (DB 탐색, 네트워크 스캔 등).
    3) 끝나면 바탕화면에 보고서 파일이 자동으로 메모장으로 열림.
       파일명: cartan_probe_YYYYMMDD_HHMMSS.txt

    ★ 이 보고서가 다음 단계의 입력값입니다 — 닫지 마세요!

  ━━━━ 3단계 : install.bat 첫 실행 (config.json 자동 생성) ━━━━

    1) [install.bat] 우클릭 → "관리자 권한으로 실행"
    2) 처음 실행이면 config.json 이 없다는 메시지 + 메모장이 자동으로 열림.
       메모장 안에 빈 값들이 표시됨.

  ━━━━ 4단계 : config.json 채우기 ━━━━

    메모장에 열린 config.json 에 아래 값을 채워넣고 저장(Ctrl+S):

    필드 9개:

    ① "AGENT_TOKEN"
       → 관리 담당자에게 받은 토큰을 큰따옴표 안에 그대로 붙여넣기

    ② "GITHUB_TOKEN"
       → 관리 담당자에게 받은 GitHub PAT 를 그대로 붙여넣기

    ③ "CARTAN_SCENARIO"
       → cartan_probe 보고서 마지막의 [CARTAN_SCENARIO 추천] 섹션에서
         "S1" 또는 "S2" 중 추천된 값으로 변경 (기본값 S2 유지 가능)

    ④ "CARTAN_DB_PATH"
       → 보고서의 ★ 표시된 주차 관련 DB 파일 전체 경로
         예: "C:\\Program Files (x86)\\TANTANCore\\CARTAN800\\bin\\ANPRDATA.mdb"
         ★ 역슬래시는 두 번 (\\) 입력!

    ⑤ "CARTAN_VISITOR_TABLE"
       → 보고서의 [6/9] 또는 [6b/9] 에서 ★ 표시된 테이블명
         예: "tVisitor"

    ⑥ "CARTAN_PLATE_COL"   → 차량번호 컬럼명     예: "carno"
    ⑦ "CARTAN_UNIT_COL"    → 동/호수 컬럼명     예: "dong"
    ⑧ "CARTAN_VALID_FROM"  → 시작 시각 컬럼명   예: "intime"
    ⑨ "CARTAN_VALID_UNTIL" → 종료 시각 컬럼명   예: "outtime"

    ★ "여기에_..." 같이 적힌 부분은 모두 채워야 합니다.
    ★ 저장은 Ctrl + S, 메모장 닫기는 X 버튼.

  ━━━━ 5단계 : install.bat 다시 실행 (실제 설치) ━━━━

    1) [install.bat] 우클릭 → "관리자 권한으로 실행"
    2) [0/6] config 유효성 검사 → OK
    3) [1/6] ~ [6/6] 자동 진행
    4) "설치 완료!" 메시지가 보이면 성공.
    5) 화면에 표시되는 STATE: 4 RUNNING 이면 정상 동작 중.

  ━━━━ 6단계 : 동작 확인 (1~2분 후) ━━━━

    1) Windows 키 + R → "services.msc" 입력 → 확인
    2) 목록에서 "OO오피스텔 주차 관리 에이전트" 찾기 → 상태 "실행 중"
    3) 관리 담당자의 텔레그램에 "서비스 시작" 알림 도착하면 정상.

──────────────────────────────────────────────────────────────
[ 설치 후 자동 동작 ]
──────────────────────────────────────────────────────────────

  - 입주민이 앱으로 방문차량을 등록하면 Cartan 에 자동 반영.
  - 1분마다 상태를 서버에 보고 (텔레그램 매일 9시·21시 점검).
  - 새 버전이 나오면 1시간 내 자동 업데이트 (별도 조작 불필요).
  - PC 재시작 시 자동으로 다시 켜집니다.

──────────────────────────────────────────────────────────────
[ 문제 발생 시 ]
──────────────────────────────────────────────────────────────

  ▸ 서비스가 "실행 중" 이 아닌 경우
    1. C:\Program Files\OfficetelParking\logs\agent.log 확인
    2. 마지막 30줄을 카카오톡으로 관리 담당자에게 전송

  ▸ 텔레그램에 "서비스 시작" 알림이 안 옴
    1. config.json 의 AGENT_TOKEN 값이 정확한지 재확인
    2. 인터넷 연결 확인 (https://your-app.vercel.app 접속 테스트)

  ▸ 서비스 수동 재시작
    services.msc → "OO오피스텔 주차 관리 에이전트" 우클릭 → 다시 시작

  ▸ 완전 재설치
    먼저 [uninstall.bat] 관리자 권한으로 실행 → 다시 [install.bat] 실행

──────────────────────────────────────────────────────────────
[ 제거 방법 ]
──────────────────────────────────────────────────────────────

  [uninstall.bat] 우클릭 → "관리자 권한으로 실행"
