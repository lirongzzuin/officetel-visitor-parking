   OO오피스텔 주차 관리 에이전트 — 설치 안내문
   작성: 관리사무소
════════════════════════════════════════════════════════════

이 프로그램은 오피스텔 방문차량 앱과 주차관제 시스템(Cartan)을
자동으로 연결하는 백그라운드 프로그램입니다.

[ 설치 방법 ]

1. USB에서 설치 폴더 전체를 PC 바탕화면에 복사합니다.
2. install.bat 파일을 마우스 오른쪽 버튼 클릭합니다.
3. "관리자 권한으로 실행" 을 선택합니다.
4. 화면의 안내에 따라 진행합니다.
5. "설치 완료!" 메시지가 나오면 완료입니다.

[ 설치 후 확인 방법 ]

1. 키보드 Windows 키 + R → "services.msc" 입력 → 확인
2. 목록에서 "OO오피스텔 주차 관리 에이전트" 를 찾습니다.
3. 상태가 "실행 중" 이면 정상입니다.

[ 이 프로그램이 하는 일 ]

- 입주민이 앱으로 방문차량을 등록하면 Cartan에 자동으로 반영합니다.
- 1분마다 상태를 서버에 보고합니다.
- 새 버전이 나오면 자동으로 업데이트됩니다. (별도 조작 불필요)
- PC를 재시작하면 자동으로 다시 켜집니다.

[ 문제가 생겼을 때 ]

- 로그 파일 위치:
    C:\Program Files\OfficetelParking\logs\agent.log

- 이 파일을 카카오톡으로 관리 담당자에게 전송하면
  원격으로 확인 및 조치합니다.

- 서비스를 수동으로 재시작하려면:
    1. Windows 키 + R → "services.msc" → 확인
    2. "OO오피스텔 주차 관리 에이전트" 우클릭 → 다시 시작

[ 제거 방법 ]

uninstall.bat 을 관리자 권한으로 실행하세요.
